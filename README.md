A modern, mobile-responsive website for **Dronas Public School**, Sadar / Badora, Betul, Madhya Pradesh.

## Website Features

- Responsive navigation, animated hero, marquee, interactive cards and scroll-to-top
- About, Academics, School Life, Gallery, Admissions and Contact sections
- Gallery filters and enquiry form (opens the visitor's email application; no form submissions are stored)
- Google Maps embedded school-location search, full-map link and one-click directions

**Production:** https://drona-public-scl.vercel.app/

## Run Locally

Open `index.html` in a browser. No Node.js installation or build step is required.
